## 발표: 내 서비스가 엄청 좋아요

안녕하세요.
저희 서비스는 혼잡한 버스를 피하고 더 편하게 탑승할 수 있도록 돕는 웹 서비스, "버스 도우미"입니다.

누가, 무엇을, 어떻게 쓰면 좋은지 먼저 말씀드리겠습니다.
어린이, 어르신, 장애가 있는 사용자가, 버스 도착 시간과 혼잡도, 정류장 대기 인원을 한 번에 확인할 수 있어서 정말 편리합니다.

그리고 단점도 솔직하게 말씀드리겠습니다.
실시간 교통 데이터가 늦게 들어오면 정보가 조금 지연될 수 있다는 단점이 있습니다.
하지만 그만큼 공식 데이터와 상태 표시를 함께 보여주기 때문에, 탑승 판단을 더 안전하게 할 수 있다는 장점이 있습니다.

---

1. 서비스 명
버스 도우미

2. 타겟(페르소나)
- 교통약자: 혼잡한 버스를 피하고 싶은 어린이, 어르신, 장애가 있는 사용자
- 보호자: 탑승 상황을 미리 확인하고 싶은 사용자
- 통학/통근 사용자: 덜 붐비는 버스를 빠르게 고르고 싶은 사용자

3. 특징
- 버스 도착 시간, 혼잡도, 대기 인원을 한 화면에서 확인
- 버스 번호와 정차 정류장까지 함께 안내
- 저상버스 여부와 접근성 정보 제공
- 모바일/PC 모두 사용 가능한 반응형 화면

4. 편리한 점
- 앱 사용 흐름이 단순함: 버스/정류장 검색 -> 상태 확인 -> 탑승 판단
- 필요한 정보만 바로 보여줘서 결정 시간이 줄어듦
- 처음 사용하는 사람도 한눈에 이해하기 쉬움

5. 핵심기능 + 부가기능
- 핵심기능
  - 버스 도착 시간 안내
  - 버스 혼잡도 안내
  - 정류장 대기 인원 안내
- 부가기능
  - 저상버스 여부 표시
  - 음성 안내(TTS)
  - 글씨 크기 조절
  - 도움 요청 및 위치 공유
  - 향후 확장: 즐겨찾기, 알림, 우회 경로 추천

6. 장점
- 빠르다: 탑승 판단에 필요한 정보가 바로 보인다
- 쉽다: 사용법이 직관적이다
- 실용적이다: 매일 반복되는 혼잡한 버스 선택 문제를 줄여준다
- 신뢰성 있다: 공식 데이터와 상태 표시를 함께 제공한다

7. 단점
- 실시간 데이터 갱신 속도에 영향을 받을 수 있다
- 하지만 이 단점 덕분에 오히려 상태 표시를 함께 확인해 더 신중하게 탑승할 수 있다

---

### 30초 마무리 멘트
저희 서비스는 거창한 기능보다,
교통약자가 매일 겪는 불편을 정확하게 해결합니다.
혼잡한 버스를 피하고, 더 안전하게 탑승할 수 있도록 도와주는 생활밀착형 서비스,
그게 바로 버스 도우미입니다. 감사합니다.
