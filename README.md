# 버스 탑승 도우미

6월 바이브 프로젝트

## 1. 문제 정의
어린이, 어르신, 장애가 있는 사용자가 혼잡한 버스를 피하고 더 편하게 탑승할 수 있도록 돕는 웹 서비스가 필요하다.

## 2. 핵심 기능 (MVP)
1. 버스 도착 시간 안내
2. 버스 탑승 인원(혼잡도) 안내
3. 정류장 대기 인원 안내
4. 버스 번호 및 버스 색깔 안내
5. 저상버스 여부 안내
6. 정류장 승하차 위치 안내
7. 혼잡도 조건 알림 기능
8. 우회 경로 추천
9. 음성 안내 강화(TTS)
10. 글씨 크기 설정(작은 글씨/보통 글씨/큰 글씨)
11. 도움 요청 버튼(보호자/도우미에게 위치 공유)
12. 데이터 신뢰도 표시(실시간/추정/지연 상태)
13. 오차 피드백 기능("실제와 달라요" 신고)
14. 배터리 절약 모드(위치/갱신 주기 조절)
15. 버스 정차 정류장 안내(이 버스가 멈추는 정류장 목록)

## 3. 기대 효과
혼잡한 버스 이용이 어려운 교통약자(어린이, 노약자, 장애인)가
상대적으로 여유 있는 버스를 선택해 더 안전하고 편하게 이동할 수 있다.

## 4. 핵심 화면 (웹)
1. 홈 화면
- 자주 타는 버스/정류장 즐겨찾기
- 현재 위치 기반 주변 정류장 요약

2. 버스 정보 화면
- 버스 도착 예상 시간(ETA)
- 현재 버스 탑승 인원/혼잡도
- 이전/다음 버스 비교

3. 정류장 정보 화면
- 정류장 대기 인원
- 시간대별 혼잡도 추이(간단 차트)

4. 접근성 설정 화면
- 글자 크기 확대
- 고대비 모드
- 음성 안내 토글(TTS)

## 5. 개발 시 고려사항

### 5-1. 보안
1. API 키 및 비밀값은 서버 환경변수로 관리
2. 사용자 입력값 검증 및 XSS/SQL Injection 방어
3. HTTPS 강제, CORS 정책 최소 권한 설정
4. 로그인 도입 시 JWT 만료/재발급 정책 및 비밀번호 해시 저장
5. 접속 로그/오류 로그에서 개인정보 마스킹

### 5-2. 기술 스택 (추천)
- 프론트엔드: React + TypeScript + Vite
- UI: Tailwind CSS + 접근성(A11y) 컴포넌트
- 백엔드: Node.js (Express or NestJS)
- DB: PostgreSQL (MVP는 SQLite도 가능)
- 실시간 데이터: WebSocket 또는 주기적 Polling(10~20초)
- 배포: Vercel(프론트) + Render/Railway(백엔드)

### 5-3. 핵심 기능 구현 포인트 (웹)
1. 즐겨찾기 버스 등록/삭제
2. ETA + 탑승 인원 + 정류장 대기 인원 동시 표시
3. 혼잡도 색상 단계
- 여유(초록), 보통(주황), 혼잡(빨강)
4. 접근성 우선
- 키보드만으로 주요 기능 사용 가능
- 스크린리더 라벨 제공

### 5-4. 디자인 방향
- 현대적, 기술적, 깔끔한 UI
- 카드형 레이아웃 + 충분한 여백
- 큰 숫자 중심 정보 디자인(도착시간, 인원)
- 색상 예시
	- 메인: 네이비/시안 계열
	- 상태: 초록/주황/빨강
	- 배경: 밝은 그레이

## 6. 예상 일정 (1개월)

### 1주차
- 요구사항 확정, 화면 구조 설계, 데이터 소스 확인

### 2주차
- 프론트 기본 화면 구현(홈/버스/정류장)
- 백엔드 API 기본 구조 구현

### 3주차
- 혼잡도 계산 로직, 즐겨찾기, 접근성 기능 구현
- 실데이터 연동 및 오류 처리

### 4주차
- 통합 테스트, 성능 점검, UI 다듬기
- 배포 및 발표용 시나리오 준비

## 7. 8시간 MVP로 축소할 경우
1. 기능 3개만 구현(도착 시간, 버스 인원, 정류장 인원)
2. 화면 1개(통합 대시보드)로 시작
3. 로그인/복잡한 통계 기능은 제외
4. 목업 데이터로 먼저 동작 확인 후 실데이터 연동
